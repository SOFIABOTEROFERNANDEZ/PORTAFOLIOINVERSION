# Guía de uso

1. `pip install -r requirements.txt` y `streamlit run main.py`.
2. **Seguimiento de portafolio**: elige instrumento y operación, fecha, ticker/nombre, cantidad, precio (0 = precio de cierre
   de yfinance para acciones/ETF) y comisión. Para CDT/TES indica tasa E.A. y vencimiento.
3. Usa **Cargar portafolio de ejemplo** para ver todo funcionando, o importa/exporta CSV.
4. Revisa las tarjetas (invertido, valor actual, rentabilidad acumulada y E.A.), la distribución renta fija/variable y las posiciones.
5. **Simulación a 1 año**: ajusta capital, historial y ponderaciones (deben sumar 100 %) en la barra lateral.
